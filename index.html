Featured Build

One Community Platform

A mobile-first service-discovery platform designed to help people find local skilled workers while giving providers a simple way to publish services and manage their profiles.

Problem

Local providers are hard to discover.

In many communities, skilled workers depend heavily on word of mouth. This makes it difficult for users to find trusted providers by category, location, or service need.

Solution

A searchable provider platform.

One Community allows providers to create accounts, publish skills, upload media, and become discoverable through category, keyword, and location-based search.

Impact

A real capstone with production thinking.

The project demonstrates full-stack development, admin oversight, testing, monitoring, deployment, backup, rollback, and maintenance planning.

Architecture and DevOps snapshot

React/Vite frontend, Node.js/Express backend, PostgreSQL database, object storage for media, Docker Compose deployment, Nginx reverse proxy, HTTPS, GitHub Actions, Prometheus, Grafana, cAdvisor, and node-exporter.
