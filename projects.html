One Community Platform

One Community is a mobile-first service-discovery platform that helps public users find local service providers such as plumbers, electricians, tailors, drivers, hairdressers, mechanics, cleaners, and other skilled workers.

Live Site API

Project Context

The project addresses a common problem in developing communities: skilled workers often provide essential services but remain hard to discover because service discovery still depends heavily on word of mouth. One Community gives providers a place to register, publish skill listings, upload media, and become searchable by category, keyword, and location.

Public users can search for local services and contact providers through familiar channels such as WhatsApp or email. Administrators manage provider activity, moderation, analytics, and operational oversight.

Architecture and Technology

The system follows a layered web platform model with a React/Vite frontend, Node.js/Express backend, PostgreSQL database, object storage for media, Nginx reverse proxy, Docker Compose deployment, GitHub Actions, GitHub Container Registry, Prometheus, Grafana, cAdvisor, and node-exporter.

Application Layer

Public platform, provider dashboard, admin portal, API workflows, authentication, OTP verification, search, geolocation, analytics, and event logging.

Data Layer

PostgreSQL stores users, providers, skills, requests, logs, events, and audit information. Object storage supports media uploads and backups.

Deployment Layer

Docker Compose, Nginx, Certbot, GitHub Actions, and GHCR support containerized deployment, HTTPS routing, releases, and rollback planning.

Monitoring Layer

Prometheus, Grafana, cAdvisor, and node-exporter provide visibility into backend health, containers, server metrics, and operational behavior.

Core Features

  • Provider registration, OTP verification, profile management, skill creation, editing, and media upload.
  • Public search by keyword, category, location, and nearby service discovery.
  • Admin oversight for provider activation, deactivation, moderation, requests, complaints, and audit visibility.
  • Analytics and monitoring through user events, login logs, system metrics, and dashboards.
  • Security and reliability practices including HTTPS, RBAC, secure sessions, backups, rollback, and maintenance planning.

Testing and Evaluation

System testing confirmed the main workflows: provider login, active-provider skill creation, inactive-provider blocking, public search, backend health checks, mobile image upload, unit tests, and runtime monitoring.

Deployment, Monitoring, and Maintenance

The report includes a practical maintenance plan: Grafana and service health review, daily database backup checks after the 2:00 a.m. backup job, weekly backend and Nginx log review, dependency and security update review, monthly restore testing, GitHub issue review, and tagged releases for rollback.

Risk planning covers security vulnerabilities, data loss, deployment failure, performance degradation, usability issues, and search limitations. Mitigations include dependency scanning, HTTPS, RBAC, password hashing, monitoring, daily backups, restore testing, tagged releases, Docker image versioning, and future load testing.

Future Roadmap

  • Expand automated end-to-end, load, security, and user acceptance testing.
  • Improve search with Elasticsearch for faster full-text, category, location, and relevance-based retrieval.
  • Add an LLM-based text search assistant for natural language service discovery.
  • Improve multilingual access, provider onboarding, and real-user feedback collection.
