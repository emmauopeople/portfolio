One Community Platform

One Community is a mobile-first service-discovery platform that helps public users find local service providers such as plumbers, electricians, tailors, drivers, hairdressers, mechanics, cleaners, and other skilled workers.

Project Problem

In many communities, skilled workers provide essential services but remain difficult to find because discovery depends heavily on word of mouth. Public users may not know where to search, and providers may not have a simple digital space to display their skills, location, and contact options.

One Community addresses this gap by creating a searchable platform where providers can register, publish skill listings, upload images, and become discoverable by service category, keyword, and location.

Architecture and Technology

The system follows a layered web platform model with a React/Vite frontend, Node.js/Express backend, PostgreSQL database, object storage for media, Nginx reverse proxy, Docker Compose deployment, GitHub Actions, Prometheus, Grafana, cAdvisor, and node-exporter.

Application Layer

Public platform, provider dashboard, admin portal, API workflows, authentication, OTP verification, search, geolocation, analytics, and event logging.

Data Layer

PostgreSQL stores users, providers, skills, requests, logs, events, and audit information. Object storage supports provider media and backup-related storage.

Deployment Layer

Docker Compose, Nginx, Certbot, GitHub Actions, and GHCR support containerized deployment, HTTPS routing, release tracking, and rollback planning.

Monitoring Layer

Prometheus, Grafana, cAdvisor, and node-exporter provide visibility into backend health, containers, server metrics, and operational behavior.

DevOps and Deployment Work

  • Containerized frontend and backend services using Docker and Docker Compose.
  • Configured Nginx reverse proxy and HTTPS routing for frontend and API domains.
  • Used GitHub Actions concepts for CI/CD, image publishing, release tracking, and deployment planning.
  • Prepared backup, rollback, restore testing, and maintenance planning for production-style operations.
  • Added monitoring visibility using Prometheus, Grafana, cAdvisor, and node-exporter.

Testing and Evaluation

System testing focused on the main user workflows and operational reliability. Testing covered provider login, active-provider skill creation, inactive-provider blocking, public search, backend health checks, media upload behavior, unit tests, and runtime monitoring.

Operations, Monitoring, and Maintenance

The project includes practical maintenance planning: Grafana and service health review, daily database backup checks, weekly backend and Nginx log review, dependency and security update review, monthly restore testing, GitHub issue review, and tagged releases for rollback.

Risk planning covers security vulnerabilities, data loss, deployment failure, performance degradation, usability issues, and search limitations. Mitigations include HTTPS, RBAC, password hashing, monitoring, daily backups, restore testing, Docker image versioning, and future load testing.

Future Roadmap

  • Expand automated end-to-end, load, security, and user acceptance testing.
  • Improve search with more advanced full-text, category, location, and relevance-based retrieval.
  • Add multilingual support for users and providers in local communities.
  • Add a simple mobile provider workflow for skill creation and media management.
  • Continue improving admin analytics, monitoring, and operational reporting.
